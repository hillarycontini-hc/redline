# Redline

Live: https://redline-rust.vercel.app/

A web app that reads a contract, lease, freelance agreement, or terms of service
and tells the reader what they are actually signing. Every risk flag quotes the
exact sentence it came from.

- `PRD.md` — the brief, signed off.
- `.scratch/redline-v1/spec.md` — the build spec, and the tickets beside it.
- `PRODUCT.md` — what stays true about the product across sessions.
- `DESIGN.md` — the visual system the build obeys.
